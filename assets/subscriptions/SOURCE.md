# Ícones de assinaturas

Os 21 SVGs deste diretório são formas vetoriais de marcas do projeto
[Simple Icons](https://github.com/simple-icons/simple-icons), revisão
`4d29a35c954699b389a834aacc97dd6e7e74143c`. Foram baixados sem
alterar os caminhos vetoriais. As cores são aplicadas pelo app conforme os
metadados de cada marca, com adaptação de contraste para tema escuro.

Simple Icons é um projeto CC0, mas a licença de cada marca pode diferir e as
marcas continuam pertencendo aos seus titulares. Os ícones aqui servem apenas
para identificar serviços informados pelo usuário; não indicam parceria ou
endosso. Consulte o [aviso do projeto](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md)
antes de redistribuir ou ampliar este catálogo.

Serviços que não constam neste conjunto usam um ícone genérico. O app não
busca imagens na rede em tempo de execução.
