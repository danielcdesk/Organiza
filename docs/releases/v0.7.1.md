# Organiza 0.7.1 - Organização unificada

## Correção

- Planejamento e Orçamento deixam de aparecer como módulos paralelos no menu.
- Desktop e celular passam a exibir um único acesso: **Organização**.
- O acesso abre a tela já existente de Planejamento e orçamento, sem alterar limites, tarefas, salário programado ou dados locais.
- A busca do aplicativo direciona resultados de orçamento para Organização.
- Atalhos rápidos móveis salvos com o antigo item Orçamento são convertidos para Organização; os demais atalhos são preservados.

## Verificação

- `flutter analyze --no-pub` sem problemas.
- 41 testes Flutter aprovados, incluindo navegação móvel e a conversão do atalho antigo.
- Dois fluxos de integração Windows aprovados em 1366×768 e 390×844; a captura do menu móvel foi atualizada.
- O APK declara `versionName 0.7.1` e `versionCode 10`, com assinatura APK v2 válida e chave RSA de 3072 bits.
- O ZIP Windows foi inspecionado e contém `organiza.exe`, `flutter_windows.dll` e `sqlite3.dll`.
