# Organiza 0.9.0 — atualização 2.1

Versão do código: `0.9.0+13`.

## O que mudou

- Organização usa exclusivamente a renda do perfil local. Alterar esse valor ajusta a distribuição, sem criar lançamento.
- A distribuição salarial aceita divisões personalizadas, percentuais, cores, ícones, ordem e categorias de despesa vinculadas. Seus limites e gastos reais aparecem juntos; os orçamentos específicos anteriores seguem disponíveis como opção.
- Finanças apresenta o extrato por mês e dia, com resumo e filtros compactos. Lançamentos podem ser editados mantendo o mesmo identificador; em séries, a edição pode atingir apenas uma ocorrência ou as próximas.
- Categorias e subcategorias aparecem com ícones nos seletores de lançamento.
- A lista de desejos ganhou edição do item existente e menu de ações mais compacto.
- Há oito cores de destaque persistidas, com suporte aos temas claro e escuro. O resumo de Relatórios ocupa menos altura.
- A Visão geral mostra um calendário recolhível de despesas pendentes, assinaturas e vencimentos de cartões.

## Dados e compatibilidade

O banco SQLite permanece no **schema 16**. As novas preferências de aparência e de distribuição são salvas em `app_settings`; não há migração destrutiva. Dados financeiros continuam locais e separados entre Windows e Android. Antes de instalar uma atualização, mantenha um backup da base existente.

## Distribuição

Esta página descreve o **código-fonte**. Os links de instalação do README ainda apontam para os pacotes 0.7.1. Um APK que atualize a instalação anterior precisa ser assinado com a mesma chave privada da versão instalada. Não trate um APK de teste como atualização oficial. O pacote Windows, quando publicado, deve conter a pasta `Release` completa.
